फ़ाइल: index.html

कैसे देखें:
1. ZIP फ़ाइल को खोलकर index.html निकालें।
2. index.html को Chrome जैसे ब्राउज़र में खोलें।
3. यह वेबसाइट का शुरुआती फ्रंटएंड डेमो है।

महत्वपूर्ण:

- वास्तविक विद्यार्थी लॉगिन, डेटाबेस, वीडियो/पीडीएफ अपलोड, ऑनलाइन टेस्ट और फीस भुगतान के लिए बैकएंड या उपयुक्त सेवाएँ जोड़नी होंगी।
- मुफ्त होस्टिंग पर प्रकाशित करने से पहले अपनी गोपनीयता नीति और संपर्क विवरण जोड़ें।
